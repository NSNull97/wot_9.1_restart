  Разрешены GET/HEAD, точный Host; POST возвращает405, страницы аккаунта410,
  account API404. Главная и ошибки направляют посетителя к каталогам.

  Обычный локальный портал сохраняет прежние формы и авторизацию.

- `scripts/package-demo.py`: архив только по разрешённому списку;
  `tests/demo.test.mjs`: поведение публичного режима и отсутствие auth endpoints.
- Данные каталога, классы, флаги, арты, CSS и характеристики не изменялись.
  Клиент, игровой сервер, пользователи и локальные конфиги на VPS не переносились.
- План: `../docs/plans/WEB_remote_demo.md`. Обновлены этот отчёт, README и STATUS.

## Команды

Локальная проверка:

```powershell
node --test --test-concurrency=1 web/tests/demo.test.mjs web/tests/network.test.mjs web/tests/vehicle-status.test.mjs
node local/web/remote-deploy/20261005-01/verify-public.mjs
```

Сборка нового архива (новый каталог, предыдущий не перезаписывается):

```powershell
python web/scripts/package-demo.py --output local/web/remote-deploy/NEW_RELEASE
```

Использован bundled Python, путь записан в истории запуска. Runtime зависимости
на VPS установлены `npm ci --omit=dev --ignore-scripts --no-audit --no-fund`.
Для демо на отдельном локальном порту:

```powershell
$env:DEMO_PORT='3094'
$env:DEMO_ORIGIN='http://127.0.0.1:3094'
npm.cmd --prefix web run start:demo
```

Управление на VPS:

```sh
systemctl status steel-front-demo.service
journalctl -u steel-front-demo.service --since today
systemctl restart steel-front-demo.service
```

Последняя команда — инструкция для дальнейшего обслуживания, дополнительный
restart после приёмки в этой задаче не выполнялся.

## Откат

На VPS выполнить:

```sh
bash /root/steel-front-deploy-20261005-01/rollback-demo.sh
```

Сценарий проверяет точную ссылку vhost, отключает только service демо и
ссылку tanks в sites-enabled, делает nginx -t/reload, сверяет duo. Release,
сертификат и доказательства сохраняются. Откат production NOT_RUN, поскольку
готовая демонстрация должна остаться доступной владельцу.

Следующий рекомендуемый шаг: открыть `https://tanks.nsnull.su` с телефона
и показать демо; перенос аккаунтов/игры в эту задачу не входит.

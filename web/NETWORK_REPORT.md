# WEB-05 · доступ по LAN и через проброс TCP80 → TCP3091

Дата: 2026-10-04, Windows x64 / Node.js 24.21.0. Область изменений —
`web/` и `local/web/`. Игровой сервер, клиент и корневой STATUS не изменялись.

## Цель и текущая приёмка

По поручению владельца запустить существующий сайт на `0.0.0.0:3091`,
сохранив вход/регистрацию через домашний Wi-Fi и внешний адрес с портом 80.

**PASS в выполненных проверках:** listener0.0.0.0:3091 и LAN работают;
http://84.39.252.98 после ручного перезапуска отдаёт страницы, правильный CSS,
SVG и миникарту с HTTP200. Браузер по этому адресу отображает оформление.
Реальный listener PID77288, старт2026-10-04 13:46:27 Asia/Yekaterinburg;
конфигурация и stdout подтверждают правильные origins, диагностика выключена.

Причиной прежнего сбоя был неверный IP из автоопределения: CSS получал HTML400.
Правильный адрес84.39.252.98 сообщил владелец. Две попытки автоматического
restart73980 были отклонены (`blocked by policy`), включая попытку после
подтверждения. Был подготовлен ручной скрипт; текущий runtime и журнал
подтверждают его результат. Агент отказ не обходил.

Проверка внешнего URL выполнена с этого ПК. Повторный проход именно через
мобильного оператора после исправления IP отдельно NOT_RUN; прежний запрос
телефона до исправления уже достигал listener.

## Реализация

- `src/network.mjs`: явные WEB_HOST/WEB_PORT/WEB_ORIGINS, ограниченная
  валидация точных HTTP origins, loopback по умолчанию.
- `src/server.mjs`: выбранный интерфейс, несколько адресов запуска;
  отключённая по умолчанию диагностика максимум 100 запросов без cookie,
  тел, query strings, посетительских IP и значений форм.
- `src/app.mjs`: Host должен быть разрешён; CSRF Origin соответствует именно
  текущему адресу, не любому другому адресу из списка. Proxy headers не доверены.
- `tests/network.test.mjs`: конфигурация и реальные HTTP-формы для LAN/WAN,
  отказ при чужих Host/Origin и X-Forwarded-Host.
- `package.json`: синтаксическая проверка нового модуля.
- `scripts/start-network.ps1`: запуск по локальному network.json.
- `scripts/restart-network.ps1`: разовая ручная замена подтверждённого PID73980,
  проверка конфигурации до остановки и готовности нового listener после запуска.
- `scripts/enable-network-firewall.ps1`: подготовленное узкое правило для
  Node/TCP3091/Ethernet/Private. **Не применялось:** пользователь уже подключается.
- `README.md`, `NETWORK_PLAN.md`, этот отчёт: запуск, ограничения, факты и откат.
- `local/web/runtime/network.json`: выбранные адреса; конфигурация исключена из Git.

## Команды запуска и проверки

```powershell
& 'D:\WoT_9.1_Server\web\scripts\start-network.ps1'
```

Запускает foreground-процесс, остановка Ctrl+C. Сначала завершить предыдущий
собственный процесс на 3091. Текущий процесс был запущен скрыто через
Start-Process с теми же WEB_HOST/PORT/ORIGINS; актуальный PID записан в
`local/web/runtime/server.pid`. Автозапуск после перезагрузки не настроен.

```powershell
Set-Location -LiteralPath 'D:\WoT_9.1_Server\web'
npm.cmd run check
npm.cmd run evidence
```

Последний прогон WEB-05: **32 теста PASS, 0 FAIL** (08:35:58 UTC), включая
CSS MIME/отсутствие HTML вместо стилей, SVG, обе группы форм, строгие Host/Origin.
`npm.cmd run check` PASS. Исправленный network.json отдельно прошёл readNetworkConfig.
Оба PowerShell-скрипта прошли Parser.ParseFile.
Firewall-скрипт не запускался; CLI launcher отдельным foreground запуском NOT_RUN.
Разовый restart-скрипт: Parser.ParseFile PASS. Исполнение агентом NOT_RUN;
результат ручного запуска OBSERVED по runtime.json, журналу и живому PID77288.

## Ограничения и откат

HTTP без TLS; Secure cookies/HSTS выключены. Конфигурация предназначена для
просмотра по запросу владельца, не является готовым публичным identity service.
Веб-профиль по-прежнему не подключён к игровому аккаунту. Роутер и Windows
firewall этим изменением не редактировались. Постоянный WAN IP/резервирование
LAN IP и автоматическое восстановление после перезапуска Windows не проверены.

Исходные четыре файла сохранены в `local/web/network/exposure-01/before/`,
их контрольные суммы — `backup-index.json`. Для отката:

1. Проверить PID и порт текущего собственного сайта и остановить только его.
2. Вернуть src/app.mjs, src/server.mjs, package.json и README.md из before/.
3. Убрать WEB_HOST/WEB_ORIGINS/WEB_TRACE_NETWORK из окружения и запустить
   `npm.cmd start`: исходный сервер слушает только 127.0.0.1:3091.
4. Сохранить SQLite и изображения без изменений. Корневые git reset/clean
   не использовать; соседняя работа не относится к этому откату.

Новые network.mjs/тест/скрипты можно сохранить отдельно; при полном откате
удалить только файлы WEB-05 после проверки списка. Firewall правило не
создавалось. Роутерный проброс 80 управляется владельцем и отключается отдельно.

**Единственный следующий шаг:** повторно открыть http://84.39.252.98
с телефона через мобильную сеть для проверки именно этого внешнего пути.

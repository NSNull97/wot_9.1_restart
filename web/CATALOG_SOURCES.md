не увеличиваются и не перезаписываются в другой формат. SVG viewBox убирает

Для переименованных машин есть явная таблица `data/modern-art-aliases.v1.json`:

Из корня проекта, с новой ещё не существующей папкой evidence для каждого запуска:

```powershell
python -B -X utf8 web/scripts/build-catalog.py --evidence local/web/catalog/rebuild-facts-01
python -B -X utf8 web/scripts/extract-catalog-media.py --evidence local/web/catalog/rebuild-media-01
& 'C:\Users\NSNull\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -B -X utf8 web/scripts/fetch-modern-renders.py --evidence local/web/catalog/rebuild-modern-01
```

Последнему скрипту нужен Pillow (использован готовый bundled runtime).
Первые два работают на стандартной библиотеке и существующем Packed XML reader.
Запуск сайта не требует ни Python, ни подключения к CDN, ни чтения клиента.

## WEB-08 · статусы техники

Статусы вычисляются из существующих `catalog.v1.json` и `catalog-research.v1.json`;
сами файлы данных не менялись. Тег `special` определяет акционную категорию и имеет
приоритет над `premium`: в этой сборке у M60/VK 72.01 (K)/Объекта 907/T95E6 тоже
есть золотая цена, из которой исходный импортёр получил флаг `premium`.
Остальные машины с этим флагом обозначаются премиумными; `event_battles` остаются
событийными. Наименования категорий — отображение этих признаков в веб-каталоге.

Правило элитности явно задано владельцем: X уровень без дополнительных модулей.
Проверяется отсутствие переходов исследования, ровно один модуль каждого из пяти
типов и отсутствие следующей машины. Это даёт 27 машин; ИС-4, E 100, WT E 100,
M48A1 Patton и Bat.-Châtillon 25 t автоматически элитными не считаются.
Выбор модуля в справочнике не меняет статус и не является исследованием на аккаунте.

Родные PNG классов остаются побайтно прежними. Венок — собственная декоративная
SVG-графика сайта, окружающая оригинальный значок; он не выдаётся за извлечённый
клиентский ресурс. Изученные `elitewindow/*.png` и `VehicleEliteIcon.png` не
подключались к сайту: первые содержат целую иллюстрацию, второй — готовую эмблему
с танком, а не отдельную рамку вокруг значка класса.

Доказательства и все 374 классификации: `../local/web/vehicle-status/run-01/`.
Полный отчёт: [VEHICLE_STATUS_REPORT.md](VEHICLE_STATUS_REPORT.md).

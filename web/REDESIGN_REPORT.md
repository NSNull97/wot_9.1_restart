# WEB-02 · Стальной рубеж

Дата: 2026-10-04, Asia/Yekaterinburg.

## Цель и результат

Оформить существующий локальный сайт в стиле приложенного игрового портала
и придумать своё название. Выполнено: «Стальной рубеж», оригинальная эмблема,
большой танковый баннер, стальные панели, оранжевые кнопки, четыре карточки
разделов, новости, концепт-арт и боковая форма входа. Регистрация, вход/выход
и редактирование профиля остаются рабочими. Страницы адаптируются к узкому экрану.

**Статус приёмки: WEB-02 PASS локально.** Игровая интеграция не входит в эту
приёмку. План до изменения: [REDESIGN_PLAN.md](REDESIGN_PLAN.md).
Запись ограничена `web/` и `local/web/`; корневой STATUS этой работой не менялся.

## Изменённые файлы

- `src/app.mjs` — главная получает существующую form session/CSRF для входа.
- `views/home.ejs` — новый портал, настоящие ссылки и раскрывающиеся новости.
- `views/partials/header.ejs`, `footer.ejs`, `icon.ejs` — название, навигация,
  эмблема, собственные иконки.
- `views/auth.ejs`, `views/account.ejs` — название и оформление форм/кабинета.
- `public/site.css`, `public/mark.svg` — адаптивные стили и эмблема.
- `public/images/battle-hero.png`, `landscape.png`, `column.png` — три оригинальные
  иллюстрации встроенного image_gen. Prompts и происхождение: [ASSETS.md](ASSETS.md).
- `tests/portal.test.mjs` — проверка нового заголовка и реального входа с главной
  с ротацией сессии, вместо входа только через отдельную страницу.
- `README.md`, `REPORT.md`, `REDESIGN_PLAN.md`, `REDESIGN_REPORT.md`, `ASSETS.md`
  — запуск, история изменений, план, приёмка и происхождение материалов.

Схема БД, версии зависимостей и правила авторизации не менялись. Клиенты,
игровые порты и соседние проекты не использовались.

## Факты и предположения

- **VERIFIED:** в шаблонах, public/src и отрисованной главной нет названия
  прежнего издателя или старого игрового бренда; внутренние якоря существуют.
- **VERIFIED:** картинки загружены, поля форм имеют labels; браузер показывает
  реальную ошибку неверного пароля и успешный вход с главной с сохранённым профилем.
- **OBSERVED:** Windows x64, Node 24.21.0, Codex in-app browser. Проверены
  ширины главной 320/390/768/1440 px, кабинет 390 px и desktop. Горизонтального
  переполнения документа в этих проверках нет; мобильное меню прокручивается отдельно.
- **INFERRED:** выбранная композиция передаёт стиль референса. Это дизайнерское
  решение, а не заявление о пиксельном совпадении.
- **UNKNOWN:** доступность названия как публичного бренда, будущий игровой
  Account API, точное историческое соответствие нарисованной техники.
  Изображения прямо подписаны как художественные иллюстрации.

## Запуск

```powershell
Set-Location -LiteralPath 'D:\WoT_9.1_Server\web'
npm.cmd start
```

Адрес: `http://127.0.0.1:3091`. Если зависимости отсутствуют, сначала `npm.cmd ci`.
В момент завершения процесс уже работает скрыто; его PID находится в
`local/web/runtime/server.pid`, stdout/stderr — рядом. Второй процесс на том же
порту запускать не нужно. Для повторения проверок: `npm.cmd run check` и
`npm.cmd run evidence` из `web/`.

## Ограничения и откат

Это локальный HTTP-портал. Игровой API не подключён, игровой вход и скачивание
клиента не открыты; каталог/форум отмечены как ещё недоступные. Публичная
публикация не выполнялась. Новый внешний вид не доказывает совместимость
сетевого сервера с клиентом. Остальные ограничения WEB-01 остаются в README.

До изменения сделан snapshot `local/web/redesign/before/` с индексом
`local/web/redesign/backup-index.json`. Для отката только оформления:

1. Проверить PID/команду процесса сайта из `server.pid` и остановить этот процесс.
2. Скопировать содержимое `before/src/app.mjs`, `before/views/`, `before/public/`,
   `before/tests/portal.test.mjs`, `before/README.md`, `before/REPORT.md` обратно
   в одноимённые пути `web/`. Новые неиспользуемые изображения и `icon.ejs`
   можно оставить; прежние шаблоны к ним не обращаются.
3. Выполнить `npm.cmd run check`, `npm.cmd run evidence`, затем `npm.cmd start`.

Схема не менялась, поэтому SQLite восстанавливать или удалять не требуется.
Не применять общий `git reset`/`git clean`: корень содержит чужую параллельную работу.

**Единственный следующий рекомендуемый шаг:** согласовать связь веб-профиля
с авторитетным игровым Account API по [GAME_ADAPTER.md](GAME_ADAPTER.md),
когда серверная сторона предоставит проверяемый контракт.

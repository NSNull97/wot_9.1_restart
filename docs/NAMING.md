# Отображаемые названия проекта

Статус: требование принято 2026-10-02; 2026-10-04 владелец утвердил
студию **GAYmDev Stutio** и рабочее название проекта **«Стальной рубеж»**.
Написание студии сохранено буквально. Названия отдельных карт ещё не утверждены.

В собственном публичном интерфейсе, оформлении и сообщениях использовать
названия проекта и студии. Упоминания исходного издателя и продукта убрать
из собственного брендинга. Это не основание переписывать происхождение
материалов, лицензии, исследовательские доказательства или технические контракты.

- Публичные названия карт и элементов UI отделены от стабильных доменных ID.
- Соответствие доменных ID клиентским ID принадлежит слою совместимости.
- Исходные имена ресурсов, пути, сетевые идентификаторы и ключи локализации
  не переименовываются массовой заменой.
- Нейминг не должен мешать исследованию родного протокола и воспроизведению
  доказательств на закреплённом клиентском manifest.

В P00–P01 ребрендинг клиента не выполнялся. Новые названия взяты у владельца.
При последующей реализации отображаемые подписи будут отдельными данными,
с явной версией и откатом, без изменения wire ID или импортированных путей.

Текущая карточка P02 Account не меняет EXE, исходные resource paths и entity ID.
Строка `Wargaming.net/WorldOfTanks` подтверждена в диагностическом native пути
preferences; она сохраняется в evidence как факт, не как публичное название.
Сессия сайта уведомлена 2026-10-04 об утверждённых названиях и границах
web→game авторизации; её изменения остаются в web/. Заголовок корневого README
тоже переведён на собственный брендинг. Массовый ребрендинг клиентских ресурсов
и штатного игрового UI в текущей карточке не выполнялся.

В последующей карточке ангара исходный UI действительно запущен и снят на PNG.
Старые подписи/welcome branding на этих изображениях ещё присутствуют; перенос
собственных отображаемых названий в native UI не объявляется выполненным.
Следующее изменение подписей должно иметь отдельный manifest/откат и сохранять
сетевые ID, пути ресурсов и ключи локализации.

## Имя игрока и вход

Уточнение владельца 2026-10-04: **вход только по почте; кириллица — в отдельном
игровом нике**. Почта не является публичным именем игрока и не передаётся в
ангарный Account.name или обзор игрового профиля. Стабильный users.id/доменный
account_id и его native databaseID не меняются из-за выбора написания ника.

В текущем срезе принят алфавит: латинские буквы, русские А–Я/а–я и Ё/ё,
цифры и подчёркивание, длина3..24 символа. Отображаемый ник сохраняет регистр
после NFC; отдельный canonical key проверяет уникальность без учёта регистра.
Старое поле users.username сохраняется как этот ключ, а не как способ входа.
display_name остаётся отдельным профильным полем. Это не обещание поддержки
произвольного Unicode или всех алфавитов в шрифтах клиента.

Исходные ASCII ники старых пользователей и их UUID сохраняются при миграции.
Неизвестные почтовые адреса не заполняются автоматически. Реальный сквозной
вход с кириллическим ником фиксируется отдельно в текущем отчёте единой учётки;
одни проверки валидаторов или схемы STRING не заменяют native trace и PNG.

## Названия серверных файлов

Уточнение владельца 2026-10-06: серверные файлы сейчас и в дальнейшем
называются по назначению, без префиксов версии клиента, номера фазы, дат
и final/new/copy. Основной source расположен в `server/`, с разделением
control, identity, gateway/protocol/account/arena/drive и physics.
Версии сохраняются в compatibility contracts, data schemas и lockfiles.
Ресурсные имена и native IDs остаются техническими идентификаторами.
Старые запускающие wrappers и pinned deployed binary сохраняют прежние
пути до отдельной миграции. [Полные правила](SOURCE_LAYOUT.md).

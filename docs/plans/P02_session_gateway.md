# P02: от первого ACK к минимальной локальной сессии

2026-10-04, Asia/Yekaterinburg. Владелец разрешил идти последовательно до
первого успешного крупного шага. Цель продолжения — минимальный native gateway
и локальная сессия P02: настоящий вход/выход, отрицательная авторизация,
дубликаты, обрыв и десять последовательных клиентских циклов.

1. Сохранить исходные 84 own files/config и полные manifests клиента.
   Original только читать; web/ и local/web/ не менять.
2. Измерить два server sequence с пропуском первого и его поздней доставкой.
   До трассы ACK при gap и его формат UNKNOWN. Сохранить неудачные опыты.
3. На измеренном контракте сделать ограниченные очереди, подтверждения и
   повторы; проверить собственными UDP controls и настоящим клиентом.
4. Разделить разбор login и проверку собственной тестовой учётной записи;
   измерить отказ неверного пароля. Минимальная сессия имеет владельца,
   состояние, дедупликацию и очистку при выходе/таймауте. Без AccountMock.
5. Настоящие циклы на одном живом gateway, повреждения, повтор и обрыв.
   Полный gate не объявлять по десяти перезапускам одноразового backend.
6. Зафиксировать доказательства, NOT_RUN для непокрытых контрактов, полный
   rollback клиента, тесты, source snapshot, STATUS и оставшиеся блокеры.

Это последовательные части одной фазы. До P03, ангара, арены, экономики и
публичного сервиса не переходить. Только собственные loopback endpoints и
disposable credentials. Диагностическая personality не подменяет native
callback и не создаёт игровые сущности. Неподдержанные fragments/messages
отклонять явно; отсутствие проверки не превращать в PASS.

Evidence: local/evidence/20261004-p02-session-gateway/.
Откат: project-before.zip, project.local.before.json, client patch-ledger и
backups каждого запуска; сохранять последующие пользовательские изменения.

и digest, 10 native cycles подряд на одном gateway PID, blackhole и recovery.

controls, 35 regression, 19 Rust / 20 Python tests PASS. Один harness FAIL
сохранён и исправлен. Full P02 PARTIAL; игровые Account/UI/arena NOT_RUN.
[Отчёт](../research/P02_LAB_GATEWAY.md). Следующий шаг — первый измеренный
native Account creation contract, без mock и без перехода к арене.

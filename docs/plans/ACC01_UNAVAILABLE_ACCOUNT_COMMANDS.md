# ACC-01: явный ответ «недоступно» на неподдерживаемые команды аккаунта

## Проблема

OBSERVED 2026-10-15 (стенды `p09e-research-01`, `p09e-main-01`): галочка
«Купить дополнительный слот» отправляет `Stats.buySlot` → `_doCmdInt3(CMD_BUY_SLOT=205,
shopRev, 0, 0)`. Gateway не знает команду, отвергает весь пакет
(`INTERACTIVE_REJECT … unmeasured Account request`) и не подтверждает его;
все последующие пакеты клиента отвергаются как вне очереди, окно «Покупка»
ждёт вечно.

## Факты исследования

- VERIFIED (`common/AccountCommands.pyc`): `RES_NOT_AVAILABLE = -10`, коды
  `CMD_*` (205 слот, 206 места в казарме, 204 премиум, 202 обмен, 106 ремонт,
  304 продажа танка, 305 продажа предмета и др.).
- VERIFIED (сканирование байткода всех мест вызова `_doCmdInt3/Int4/IntArr`):
  в `Stats`, `Inventory`, `Shop`, `Trader`, запросах информации об игроке
  callback — `lambda(requestID, resultID, errorStr, ext={})`; уже измеренный
  ответ `onCmdResponseExt` (`0x4d`, `-10`, пустой `ext`) доходит до
  обработчика ошибки UI. Так же уже отвечаем на CMD 108 и на отказы P09E.
- VERIFIED: у `prb_*`, `completeTutorial`, `verifyFinPassword` и части
  `Trader` callback трёхаргументный; ответ с `ext` уронил бы их. Метод
  `onCmdResponse` (без `ext`) в gateway не измерен — UNKNOWN.

## Контракт

Gateway в интерактивном режиме отвечает `RES_NOT_AVAILABLE` без изменения
состояния на корректно сформированную команду из явного списка (по семейству
метода), если её не забрал включённый сервис. Длина массива `doCmdIntArr`
точная и не больше 100. Идентификатор запроса один раз в общем пространстве.
Команды вне списка, трёхаргументные и команды синхронизации остаются строгими.
Служебные ветки найма (`0x90`) и боеприпасов/раскладки (`0x97`) теперь
проверяют номер команды и не перехватывают чужие команды.

## Проверки и приёмка

1. Unit: слот → `Unavailable`; трёхаргументные и неизвестные — отказ;
   повтор ID, нулевой ID, неверная длина массива — отказ; CMD 303 —
   казарма при включённой казарме, иначе «недоступно»; сессия отвечает и
   принимает следующий пакет по порядку.
2. Полный набор gateway.
3. Native: галочка «Купить дополнительный слот» даёт сообщение об ошибке,
   окно не зависает, дальнейшие действия работают.

**Решение — патч клиента по флагу.** `tools/battle_ui_marker_flash.py` собирает `res_mods/0.9.1/gui/scaleform/VehicleMarkersManager.swf`
из оригинала по закреплённому SHA-256. Все родные теги не меняются, добавлен один DoAction перед единственным `ShowFrame`. Он один раз
оборачивает `HealthBar.prototype.setLabel`: родной вызов, затем на метке `blue` полоса получает `ColorMatrixFilter`, на любой другой фильтры
снимаются. После смены кадра полоса заново выставляется по здоровью (`updateHealthBar`): смена кадра может дать новый экземпляр полосы.

Матрица — **проектный выбор**: каждая строка в сумме даёт 1, серые остаются серыми, `greenColor` 123 236 55 переходит ровно в `blueColor`
0 234 255 из `gui_colors.xml`. Число HP оставлено родным, белым: на живых скриншотах Lesta оно белое у всех маркеров.

Включение: `prepare --team-killer-marker` (требует `--enable-profile13-battle`). Голубых союзников даёт только ключ шлюза `team_score` из
UI-06. Без флага фильм маркеров байт в байт родной. Откат: `rollback` клиента или повторный `prepare` без флага.

**Причина:** ряд машин — родная функция, но у аккаунта владельца выключена. Это ошибка хранения настроек UI-01, а не интерфейса боя. Поскольку
шлюз объявляет версию 11 без разделов, клиент не записал значения по умолчанию. Первая же смена пункта на вкладке «Игра» сохранила его поверх
нуля, и вместе с этим обнулились остальные пункты GAME. По той же причине у владельца сейчас выключены динамическая камера, стабилизация,
запись реплеев, фильтры чата и другие пункты GAME, если владелец не менял их сам. SOUND (ключ 3) тоже 0.

**Что сделать сейчас:** на вкладке «Игра» отметить «Показывать маркеры техники на панели счёта» и сохранить. Клиент запишет бит поверх
сохранённых 32. Ряд появится родным путём, без патча и без смены шлюза. Заодно стоит проверить остальные пункты вкладки.

**Не исправлено здесь:** чтобы новые аккаунты получали значения по умолчанию, нужна отдельная карточка по хранению настроек UI-01. Вариант —
не объявлять версию у аккаунта без сохранённых ключей, тогда клиент сам запишет значения по умолчанию, как при первом входе. Это меняет
опубликованное состояние всех аккаунтов и фикстуры, поэтому в эту карточку не входит.

**Полоса суммарного HP команд — не делается.** В #717 её нет. Текущее HP противника клиент знает только для машин в зоне видимости: в
`arena.vehicles` здоровья нет. Сумма по противнику была бы либо неверной, либо потребовала бы раскрыть HP скрытых машин (AGENTS: скрытое не
отправляется). Полоса только по своей команде вводила бы в заблуждение рядом с пустой полосой противника.

## Ограничения

- Native **NOT_RUN**. AS2-машина доказывает, что байты делают написанное, а не то, что Scaleform нарисует фильтр на полосе.
- Вид полосы под фильтром на native не сверен; если градиент полосы содержит не зелёные тона, они сдвинутся по той же матрице.
- `res_mods` перекрывает весь `VehicleMarkersManager.swf`. Другой мод, заменяющий тот же файл, с флагом несовместим.
- Ряд машин после включения настройки на native не проверен; данные для него те же, что для ушей, они у владельца работают.

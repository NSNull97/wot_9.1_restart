непринятой карточки; это явное ночное исключение из требования ветки только main.

не создают symlink/junction к local ресурсам. Не копировать тяжёлые клиентские данные.

остаётся обычным --no-ff/push/remote SHA. Проверять реальные runtime артефакты,
не менять frozen source gates под фикстуры. Оригинал клиента только read-only.

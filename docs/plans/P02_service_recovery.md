# P02: восстановление локальной службы после исчезновения процессов

Дата: 2026-10-06, Asia/Yekaterinburg.

Задача владельца: команда обычного запуска отказывает из-за оставшегося
supervisor.lock. Карточка поездки уже завершена; игровой код не меняется.

1. Сохранить исходники, state.json, supervisor.lock, конфигурации и их SHA256;
   проверить только собственные PID и локальные endpoints.
2. Добавить read-only статус фактического состояния процессов и консервативное
   восстановление: все старые PID должны быть подтверждённо отсутствующими,
   lock должен совпадать с известным supervisor, порты свободны. Живой PID,
   отказ доступа, другой владелец или изменившийся файл блокируют восстановление.
3. Архивировать точные байты старого состояния/lock; сериализовать восстановление
   и создание lock. Закрыть утечку lock при раннем исключении в serve.
4. Запустить проверки отказов и настоящие проверки процессов Windows; выполнить
   восстановление этого стенда, обычный запуск и проверить реальные endpoints.
5. Обновить STATUS и отдельный отчёт с PASS/FAIL/NOT_RUN, командами и откатом.

Оригинальный клиент, установленный пакет normal014, игровые данные и реализация
поездки не меняются. Внешний сайт сохраняет отдельного владельца; действующий
процесс сайта не останавливается. Автозапуск игрового окна не нужен.

# P05C — одна физическая сцена

Ночная реализация разрешена владельцем 2026-10-16 без ожидания ручных проверок.
Native-приёмка остаётся NOT_RUN до проверки владельца; автоматический результат
не превращает её в PASS. Работа начинается от P08B `c7999e6` в отдельном worktree.

1. Новый opt-in IPC7: один Jolt PhysicsSystem, 1–6 source-bound машин для
   component tests (боевой coordinator допускает 2–6), все команды до одного
   update, все poses одним frame. Legacy IPC1–6 сохраняются.
2. Сохранить P05B TrackedHandling и source profiles, один каталог и единичный
   prepared/ACK commit. Контакт танков — обычный solid Jolt; урон тарана вне scope.
3. Checked Rust batch client и небольшой coordinator; runtime integration в
   World/native publication выполняется отдельно после P08C.
4. Реальные worker gates: mixed contact, шесть тел / один PID / одна шкала,
   independent controls, повторяемость и исходные handling scenarios; malformed
   IPC, stale pins и отсутствие частичного batch commit.
5. Native: смешанный таран, 2–6 клиентов, повторный бой. До запуска NOT_RUN.

Ресурсы читаются по проверенным абсолютным путям из
`D:/WoT_9.1_Server/local`; никаких junction/symlink/копий больших ресурсов.
Новый код и результаты сборок находятся в worktree. Лимиты и факты фиксируются
в `docs/research/P05C_SHARED_PHYSICS.md`. План удалить после слияния карточки.

# P02 — одна родная команда движения и серверное обновление позиции

2026-10-05. Владелец разрешил следующий проверяемый шаг после Ready01.
Q=`local/evidence/20261005-p02-arena-movement/`.

Цель: установить и проверить настоящим #717 путь команды движения собственного
МС-1 и родной путь серверного обновления/коррекции положения. Это ограниченный
лабораторный опыт, не приёмка исторического контроллера, коллизий или полного боя.

1. Прочитать AGENTS/STATUS/архитектуру/ruleset и предыдущую приёмку.
   Сохранить authored sources, четыре конфигурации, profile002, normal012 ledger
   и согласованные SQLite backups. Проверить mutex/процессы и существующие
   изменения. Оригинал только читать; все производные ресурсы оставить в local.
2. По original .def/pyc/PE установить vehicle_moveWith, native flags, условия
   допуска команды и методы position/direction/control. Отдельно исследовать
   локальный фильтр/physics и данные места появления. Не угадывать codec/ID.
3. После доказанного контракта реализовать один явный диагностический режим:
   действующая авторизация/своя машина/фаза, bounded parse, команда/остановка,
   ограниченное серверное изменение собственного состояния и native публикация.
   Никакие присланные клиентом координаты не становятся авторитетными.
   Не выдавать лабораторное изменение позиции за полноценную физику движения.
4. Диагностический сценарий может вызвать измеренный оригинальный метод своего
   PlayerAvatar и читать состояние/сохранять native PNG. Не управлять мышью или
   клавиатурой, не присваивать клиенту позицию/filter state/clock, не подменять
   original lifecycle. Внешний EXE timeout/kill не использовать. Если штатный
   метод требует активной фазы, сначала документировать её минимальные условия;
   не объявлять переход фазы готовностью игрового боя.
5. Guarded build, fresh one-shot install и настоящий loopback запуск после
   хеширования/backup затрагиваемых файлов. Связать исходный вызов, реальные
   пакеты, серверное состояние, native readback и корректное завершение.
   Ложный результат/неподдерживаемый кодек оставлять FAIL/UNKNOWN, не обходить
   клиентским присваиванием или собственным протоколом.
6. Независимая проверка и необходимые negative tests. Сохранить generated replay
   с exact hash/time binding и восстановить baseline. Вернуть ordinary сервер
   и новый обычный пакет, сверить original/research/profiles/configs, обновить
   STATUS/MISSING_INPUTS/отчёт. Незапущенное — NOT_RUN. Остановиться на карточке.

Не входят: полноценный Jolt-контроллер, исторические коэффициенты движения,
баллистика/урон/стрельба, экономика, второй игрок и production масштабирование.
Распределение: wire — native transport/control/position; GUI — original input
и наблюдение; data — пространственные данные и независимая приёмка; root —
baseline, общая интеграция, настоящие запуски и итог. Владение кодом согласуется
после исследования. Сторонняя работа с сайтом сохраняется отдельно.

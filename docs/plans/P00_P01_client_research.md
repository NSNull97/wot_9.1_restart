# P00–P01: локальный аудит и узкие эксперименты

Дата: 2026-10-02. Задача: `prompts/FIRST_PROMPT.md` и уточнения владельца.

## Границы

Только этот проект, две явно разрешённые клиентские папки и `local/`.
Оригинал только читается. Исследовательские изменения требуют исходного
SHA-256, резервной копии, журнала и проверяемого отката. Внешние игровые
серверы не используются. Следующие фазы не начинаются.

## Последовательность

1. Сохранить исходный пакет, проверить его manifest, подготовить Git-исключения,
   локальную конфигурацию и журнал инструментов. Git до начала отсутствовал.
2. Написать ограниченные read-only утилиты инвентаризации, SHA-256 и сравнения
   двух копий; исследовать версии, ресурсы, PE и заголовки bytecode.
3. Исследовать definitions/aliases, клиентские точки входа, дескрипторы и один
   геометрический фрагмент. Извлечённые клиентские материалы только в `local/`.
4. Закрепить исходники wg-toolkit-rs и лицензию; попробовать сборку и чтение
   реальных ресурсов. Проверить отдельный headless physics spike.
5. После определения безопасного способа запуска выполнить обратимую
   диагностику и попытку соединения только с loopback. При невозможности
   гарантировать изоляцию не запускать клиент; записать конкретный блокер.
6. Запустить положительные/отрицательные тесты инструментов, повторить
   контроль целостности, подготовить шесть отчётов, NAMING, MISSING_INPUTS
   и STATUS. Отделить PASS инструментов от приёмки реального транспорта.

## Доказательства и завершение

Run ID: `20261002-p00-p01`. Локальная база: `local/evidence/20261002-p00-p01/`.
Результаты помечаются VERIFIED / OBSERVED / INFERRED / UNKNOWN; проверки —
PASS / FAIL / NOT_RUN. Остановка после P00–P01, включая незакрытые критерии.
Риски: неустановленное происхождение архива, старые пользовательские логи,
неизвестные сериализаторы/шифрование, ограничения GUI и сборочных инструментов.
Никакие успешные unit-тесты не означают сетевой бой или историческую физику.

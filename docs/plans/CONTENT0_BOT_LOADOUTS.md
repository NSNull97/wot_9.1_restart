# CONTENT-0. Боевые комплектации ботов

База `3a76ad01`. Проверяем на отдельном локальном стенде с копией БД шага 5.

1. Разрешить готовые нестоковые сборки в обычном подборе. Сохранять исходный тип машины,
   уровень, боевой профиль, физику и боекомплект выбранного орудия.
2. Разложить реальные типы снарядов по БК и подключить их смену через штатную перезарядку.
   Соблюдать ограничения ёмкости и число снарядов орудия.
3. Добавить САУ из проверенных профилей test_lab. Учитывать командный лимит и засвет,
   проверять траекторию и союзников перед выстрелом.
4. Прогнать тесты состава, стрельбы и готовности арены. В бою проверить реальные нестоковые
   сборки, расходы каждого типа снаряда, выстрелы САУ и возврат в ангар.

Режим неподвижных мишеней с подрывом БК сохраняет прежнюю комплектацию и поведение.

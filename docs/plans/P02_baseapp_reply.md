# P02: ответ BaseApp и первое следующее сообщение

Дата: 2026-10-04, Asia/Yekaterinburg. Основание: «давай» владельца после
завершённой карточки LoginSuccess → первый BaseApp request.

Цель: настоящий закреплённый клиент должен принять ограниченный ответ
собственного BaseApp endpoint и отправить первое следующее native-сообщение.
Account, ангар, арена и полный gate P02 в эту карточку не входят.

1. Сохранить собственные файлы и config до изменений; проверить mutex и
   полные manifests обеих клиентских копий. Оригинал только читается.
2. Изучить кандидат ответа в закреплённом toolkit и наблюдаемые признаки
   соответствующего пути в EXE. Сначала обозначить гипотезы; подтвердить
   формат реальным клиентским обменом, не round-trip собственного кодера.
3. Добавить отдельный bounded профиль backend и двусторонний capture BaseApp.
   Только 127.0.0.1; предыдущие рабочие профили сохранить. Никаких entity stubs.
4. Перед временным client patch — hash, backup, ledger; после каждого опыта
   восстановить файлы. Чужую игровую копию не останавливать и mutex не обходить.
5. Проверить следующий пакет/клиентский callback, ошибки длины/шифрования,
   токена и повторы. При неудаче сохранить FAIL, исследовать причину и
   повторить только изменённую гипотезу.
6. Проверить применимую регрессию, полный откат, Git exclusions и завершение
   своих процессов. Отчёт со смещениями/хешами/командами и UNKNOWN; остановка.

Исходные гипотезы: u32 session token в reply и Blowfish packet filter toolkit
могут подходить, но его modern prefix/BaseApp layout уже отличаются от 0.9.1.
Channel flags, ACK/sequence, первое client message ID и точные crypto footer
не считать установленными до trace. LOGGED_ON ещё не означает наличие Account.

Evidence root: `local/evidence/20261004-p02-baseapp-reply/`.
Откат проекта: `project-before.zip` + `project.local.before.json` в этом root;
client rollback — существующий `tools/client_probe.py restore --out <run>`.

## Результат

PASS узкой карточки: два native runs, LOGGED_ON и первый encrypted packet
с токеном BaseApp reply; 75 negative/control cases, 8 Rust / 20 Python tests,
real redirect regression. Полный gate P02 NOT_RUN. Mutex освобождён владельцем
до запуска; все client patches откатились. [Отчёт](../research/P02_BASEAPP_REPLY.md).

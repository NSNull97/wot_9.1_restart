## Шаги

1. **Экспорт одной утилитой** `tools/map_package.py` (git): перенос проверенных
   алгоритмов из evidence-скриптов без изменения математики, обобщённых на любые
   границы/размер тайла. Пакет карты: `terrain.*` (сетка высот), `physics/obstacles.*`
   (маска 18, вход Jolt), `projectile/obstacles.*` (маска 128 + флаги), `arena.json`
   (границы, спавны, базы/точки захвата по типам боя), `destructibles.json`
   (инвентарь по семействам, native-индекс по чанку со ссылкой на источник индекса,
   исключения с причинами), `package.json` (SHA-256 каждого файла и входов клиента).
   Оригинал клиента только читается. Регрессия: для Карелии и Прохоровки буферы
   рельефа/физики/снарядов побайтно равны закреплённым в `map_profile.rs`.
2. **Реестр карт как данные**: `server/contracts/map_registry.json` (id арены,
   имя ассета, сетка рельефа, пины пакета/манифестов, счётчики). `MapId` — значение
   из реестра, не ветка enum. Карелия/Прохоровка — те же пины, что сейчас (тест
   побайтного равенства профилей). Gateway (terrain, fragiles, world, worker,
   scene_worker, codec) и физика (Program.cs, CheckedInput.cs) читают реестр.
3. **Доказательство на 3 картах**: Карелия, Прохоровка + `02_malinovka` (12×12, все
   семейства, ctf/domination). Для новой карты: загрузка рельефа/препятствий в gateway,
   оседание танка в Jolt на спавнах обеих команд, каталог разрушаемого с исключениями.
   Семейства (`fallingAtoms`, `structures`) закрываются только при VERIFIED контракте
   клиента; иначе — явное исключение с причиной.
4. **Пакетный отчёт по 44 картам**: какие экспортируются чисто, какие требуют работы.
5. Проверки: Python-тесты утилиты, тесты Rust/C#, физика для затронутых сцен,
   канонический gate gateway (чистое дерево). Native-приёмка — владелец (NOT_RUN).

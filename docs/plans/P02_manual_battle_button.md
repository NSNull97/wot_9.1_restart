# P02: ручное нажатие «В бой!» в ordinary клиенте

Дата: 2026-10-06, Asia/Yekaterinburg.

Владелец подтвердил: normal014 с готовым МС-1 показывает старый отказ ангара.
Логи устанавливают ordinary policy, но вызовы не проходят первый фильтр
mapID/actionName. Точные аргументы UNKNOWN; ночной сценарий вызывал (0, '').

1. Сохранить before hashes/исходники/установленные настройки, владельческий
   screenshot и точные ordinary logs. Оригинальный клиент только чтение.
2. Добавить ограниченный сбор формы аргументов перед фильтром, без repr
   посторонних объектов и без вызова queue для неизвестных значений.
3. Установить отдельный версионированный пакет в закрытую исследовательскую
   копию с backups/rollback; получить один настоящий ручной клик без таймера.
4. Нормализовать только подтверждённый callback случайной карты в native INT32,
   сохранив существующие readiness/ammo/Account/MS1/CAPTCHA проверки.
5. Проверить отрицательные варианты и реальный ручной вход на карту, возврат;
   обновить STATUS и отчёт. До этого manual button acceptance не PASS.

Физика, maps pool, экономика и новые фазы не меняются. Backend уже работает;
его не требуется перезапускать для сбора client callback.

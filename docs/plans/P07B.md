# P07B — серверный interest set и родной AoI #717

2026-10-16. Ночная подготовка по разрешению владельца без остановок на ручные
проверки. Активная родительская карточка пока P05C; этот компонент готовится
отдельно, без изменения её runtime и без коммита в её ветку. Интеграция — после
автоматических gates P05C в отдельной зависимой ветке P07B. Native до утра NOT_RUN.

1. Закрепить original #717 enter/leave AoI, source consumers и stock
   `circularVisionRadius` установленных башен МС-1/ИС-7. Сведения и границы —
   [P07B_NATIVE_INTEREST](../research/P07B_NATIVE_INTEREST.md).
2. Подготовить pure bounded `shared/visibility.rs`: ≤6 слотов, authoritative
   server poses/sight points/team/profile range, явная own/allies policy,
   enemies только range + read-only LOS callback. Ошибки не возвращают частичный
   набор и не разрешают повторную публикацию прежнего набора.
3. Подготовить pure std `shared/interest_wire.rs`: ≤6 записей, только
   слоты/sequence/desired, Hidden/Announced/Leaving. Отдельные queue proposals,
   mark после enqueue, stale revision guards, leave ACK перед повторным enter.
   Проверить компоненты отдельным `rustc --test`, без Cargo/Jolt: граница range,
   разные stock ranges, occlusion, все6 получателей/целей, invalid snapshot,
   late LOS error после первого allow, balanced AoI cycles, LOS flaps, retries,
   cumulative/selective ACK. Native/сетевой засвет этим не доказан. Выполнено:
   `local/build/server/p07b-components04/receipt.json`, 12PASS/0ignored; модули
   пока не объявлены в существующем runtime.
4. Root интегрирует каждый publication tick с настоящим terrain/static BVH LOS,
   состояниями Hidden/EnterPending/CreatePending/Visible/LeavePending, epoch,
   reliable retry/ACK и контролем новых/устаревших entity requests. Все пути
   позиций, HP, aim, fire/effects/catch-up фильтруются до queue.
5. Пройти wire/rollback/retry/packet-absence gates текущего source head; отдельно
   owner native: исчезновение за рельефом/стеной, повторный засвет, смешанные
   машины, ≥2 клиентов. Без ручного результата оставить NOT_RUN и не сливать main.

Явная v1 test_lab policy: своя машина и союзники остаются в interest set;
противник требует inclusive 3D centre distance и одного server sight ray.
Sight point берётся из серверной геометрии с документированным смещением.
Камуфляж, кусты, radio sharing, historical delay и retention не моделируются;
исторической точностью этого алгоритма не объявлять.

Критерий карточки — скрытые точные координаты и эффекты не уходят получателю,
а original #717 корректно проходит обычное появление/исчезновение/повторный вход.
Откат отдельной подготовки — удалить новый модуль/план и дополнение исследования;
до интеграции существующий runtime от этого не меняется.

  строки склада через существующую миграцию `extend_catalog_shells`. Реестр: профиль у каждой сборки с профилем

  0.9.1 — проверить по байткоду), строка `p09c_ammo_mount` переходит на установку новой пары с нулями; загрузка и
  покупка снарядов (`BUY_SHELLS`, сервис P09C) — по установке текущей пары. Проверка `_ammo_projection` — установка
  по текущим модулям машины.
- **4c Бой.** Снять отказ этапа 1; шлюз: разброс по орудию сборки (строка на пару), физика: коробка башни сборки из
  её части башни, грунт — у всех сборок; MODVOL: корпус всегда, башня — по разметке этой башни, если она есть в
  архиве скинов, иначе лабораторная коробка только для башни (строка в логе).
- **4d** Снаряды за золото и окно «Склад» — по описи 0.9.1 (`premium_gold_flag` есть в таблице; бесплатно до ECON).

# Следующие карточки после FULL-TEST (черновик, 2026-10-20)

Не начаты; порядок — предложение. Каждая — своя ветка от интеграционной головы
`codex/full-test-20261019`, нативная приёмка владельцем.

1. **CREW-V2 — ёмкость экипажа под нулевой экономикой.** Сейчас 16 человек за всё
   время аккаунта (у A на стенде -04 бесплатный найм исчерпан, у B осталось 3).
   Сервер: версия контракта `p04m-pool-crew.v2` (ёмкость ≥192, паспорт имени/иконки
   по модулю каталога — для №1–16 совпадает с v1), миграция SQLite по образцу
   `PoolStore._rebuild_crew_tables` (`p04d_crew_member`/`p04j_retired_member`
   `native_id BETWEEN 1 AND 16`, `p04d_crew_meta` `next_native_id ≤17`, `free_left ≤13`),
   `LIMIT 17` в `_crew_projection`. Клиент: `MAX_TANKMEN = 16` и проверки ростера в
   `client_patch/p04h…p04k_crew_ui.py`; переустановка a/b.
2. **CREW-UI-POOL — UI экипажа и БК для купленных Т-26/Т-34/Т-34-85.** Клиентские
   патчи P04F–P04K и P09D жёстко держат `VEHICLES = {1: MS-1, 2: IS-7}`. Обобщить на
   типы пула (роли из `p04m_pool_crew.PINS`, раскладки из `p04m_pool_store.SHELL_ROWS`).
   До этого — `tools/full_test_stand.py provision`.
3. **TURRET-COLLIDE — коллизия оторванной башни.** Уточнить у владельца: танки
   проезжают сквозь лежащий ствол и/или снаряды. Танки: новая IPC-операция сцены
   (статическое тело по позе `Resting`, версия протокола IPC7+1) в `server/physics` и
   `drive/scene_worker.rs`. Снаряды: меш башни в запросе столкновений `model.rs`.
4. **MAPS-ALL — разрушаемость и бои на всех картах.** В клиенте 44 карты, сервер

   физика, каталог разрушаемого с native ID, затем семейства `fallingAtoms`/структуры.
5. **BATTLE-POOL-N — бой на других купленных машинах.** Импорт боевых профилей
   (физика, броня, орудие, модули) по образцу P04M для следующих машин пула.
   Допуск — все четыре слоя: клиент `PROFILE13_VEHICLES` (экипаж в порядке ролей

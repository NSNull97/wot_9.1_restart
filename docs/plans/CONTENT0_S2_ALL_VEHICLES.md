## Подшаги (предложение, порядок — по объёму и зависимостям)

1. **2.1 Каталог всех готовых машин** — все машины с собранным профилем (кроме исключённых) в каталог main и test_lab;
   стенд -16 с ними; бой владельца на выборке. Самый большой выигрыш без новой механики.
2. **2.2 Танки с 1–2 снарядами** — правило SPG-02 для любых машин.
3. **2.3 Опоры ходовой** — обобщить `_supports` по реальным описаниям 41 машины.
4. **2.4 САУ в main** — правила SPG-01/02 из test_lab в main (решение владельца).
5. **2.5 Огибающие физики и прицела, коллизии** — по машинам. Сюда же 6 машин, снятых из каталога 2.1 ночью 11.11: их
   передний/задний сектор наводки шире базового, а передача угла клиенту берёт базовый (`aim::source_controller_supported`):
   AMX 13 75, Pz.IV Ausf. H, Ke-Ni, Ke-Ni B, Gun Carrier Churchill, M4A2E4.
6. **2.6 Автоматические орудия** — стрельба очередью (новая механика вооружения).

Пределы размеров: профиль и журнал команды растут с числом машин и экипажей (на -15 девять машин дали 17,4 КБ
контекста при пределе 16 КБ — поднят до 128 КБ). Перед 2.1 — пересчитать пределы (`MAX_STATE`, профиль 256 КБ) для
аккаунта со всеми машинами.

Каждый подшаг — бой владельца на стенде, gate и Python-набор, слияние в main.

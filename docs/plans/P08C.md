# P08C — серверный цикл боя и native итоги

Ветка codex/p08c-battle-lifecycle от P08B c7999e6. Прямое ночное разрешение
владельца 2026-10-16 допускает зависимую ветку до утреннего owner gate P08B;
не допускает выдавать NOT_RUN за PASS или сливать непринятое в main.

## Цель

Один authoritative цикл: ожидание готовности → отсчёт → бой900с → исход
(уничтожение/захват/таймер) → итоги → штатный возврат. Погибший остаётся
наблюдателем до итога либо сам выходит. Родные #717 timer/capture/death/results
получают только серверные данные, с журналом расхода и test_lab free repair/0XP.

## Исследование и реализация

1. Закрепить original #717 constants/ClientArena/BattleResultsCache/Avatar/Account
   bytecode и map bases/roundLength. Не исполнять оригинальные клиентские модули.
2. Отдельная доменная машина состояний с монотонным серверным временем,
   детерминированным capture и замороженным exactly-once исходом. Radius/rate,
   wait/countdown/afterbattle policy явно test_lab, не историческое обещание.
3. Включить её в profile13 template/World, команды до/после боя не расходуют БК,
   остановка контроллеров не доверяет клиентскому времени/HP/позиции.
4. Отдельный bounded native wire module: period3, kill6, capture8/9 и exact
   compact result stream100; Account1500/1501 и confirmation только исследованные.
   Результат содержит фактические shots/damage/kills/HP, credits/XP0.
5. Сохранение/доставка результатов через существующий single SQLite writer,
   привязка owner/battle/run/команд, границы парсинга, идемпотентность и recovery.
6. Meaningful domain/transport/writer tests; полный gateway suite/build на
   текущем runtime; native/UI/audio/утренние многократные бои NOT_RUN.

## Проверки

Ожидание всех ready; countdown запрещает движение/выстрел; exact time boundary;
таймер даёт ничью; уничтожение/одновременная гибель; capture/contested/reset on
damage; никакой смены замороженного исхода; spectator/leave/disconnect; повторный
бой; отказ/повтор/atomicrollback writer/delivery; чужие/повреждённые results denied.
Legacy STAB/P08B тесты сохраняются. Не обещать P05C tank collision/6clients,
P07B скрытие, P06T shell families или P10B комнаты этой карточкой.

## Утро и откат

Подготовить source-bound launcher и короткую матрицу countdown/timer/capture/
death/results/return/repeat. Без owner feedback native gate остаётся NOT_RUN.
Откат — ветка/commits P08C, собственная версия result schema и client ledger.

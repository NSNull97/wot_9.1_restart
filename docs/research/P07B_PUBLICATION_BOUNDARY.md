## Contract

`Recipient` is a small, transport-independent gate. The integration layer
supplies:

1. `battle_epoch` and `joined_tick` for the current battle/connection;
2. the current visibility and enter/create epoch for each actor;
3. opaque `PointInterest` tokens generated by the authoritative current LOS /
   point-interest pass, bound to the source actor's current epoch;
4. source events after authoritative collision and flight validation.

The gate returns typed `PublicEvent`s. It does not encode IDs, call native
methods, or mutate world physics.

For a visible shooter, `TerrainTerminal` may retain the shooter slot for the
normal visible path. For a hidden shooter, the only permitted output is an
anonymous `TerrainTerminal` with no shooter field and only while the current
recipient point-interest token matches. A hidden `TracerStart`, `TracerStop`,
or `VehicleImpact` is suppressed. A terrain terminal with a stale token is
suppressed rather than converted into `stopTracer`, because that would either
leak a hidden source or replay a private point after a visibility flap.

The queue is bounded (`MAX_PENDING` and a per-recipient capacity); the
once-only ledger is sized for four publication kinds across the six-seat
laboratory shot ceiling and is cleared on battle reset. On a full
window, optional terrain FX are backpressured; a visible tracer start may
evict one lower-priority pending item. Queue admission is the point at which
the once-only ledger is updated. A pending source event is checked again at
drain time, so an epoch change, hide, expired point-interest, or battle reset
cannot turn an old private event into public bytes.

## Integration contract and current seam

The root session integrates this module at the existing publication seam in
`shared/server.rs` without copying private state into a shared packet:

* construct one `Recipient` per native session/battle after the current
  `interest_wire::Book` has a valid Enter/Create epoch;
* map `Book::announcement_sequence(slot)` (or the equivalent current
  create/epoch pair) to `ActorRef::epoch`; call `set_actor` from the fresh
  authoritative visibility snapshot before publishing deltas;
* issue a point-interest token only from the current authoritative LOS /
  projectile-point query and call `set_point_interest`; do not derive it from
  a client coordinate or packet;
* submit tracer, terrain-terminal, and vehicle-impact source records before
  the existing `queue_private` call, then map each drained `PublicEvent` to
  `wire`, `terrain_wire`, or `impact_wire` bytes;
* call `reset_battle` on native rejoin/new battle and pass the actual current
  tick; do not seed the new recipient with old `shot_cursor`/FX bytes;
* retain the existing reliable ACK/epoch barrier. `Recipient::Queued` is not
  a native ACK and must not be treated as one.

`model.rs` now owns source-point/range/LOS and Sixth Sense generation. The focused server tests exercise snapshots, enter/create/leave epochs, late requests, death/results and hidden-shooter payload paths. Native client publication remains **NATIVE_NOT_RUN**.

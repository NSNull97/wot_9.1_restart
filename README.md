# Стальной рубеж

**GAYmDev Stutio · рабочее название утверждено владельцем 4 октября 2026 года.**
Собственный брендинг отделён от технических имён клиента и происхождения материалов:
[правила названий](docs/NAMING.md).

Цель: отдельный авторитетный сервер для настоящих сетевых боёв на клиенте WoT 0.9.1
(#717), затем — небольшой самостоятельный игровой сервис с аккаунтами, ангаром,
комнатами, подбором боёв и прогрессией. «Орион» — ориентир пользовательского результата,
а не подтверждённая архитектура или исходная база.

## Устройство

- `server/gateway` — Rust: протокол #717, вход, ангар, команды аккаунта, общий бой
  ([команды и дерево](server/README.md)). `server/physics` — C# worker на Jolt.
- `tools/` — Python: хранилища аккаунта (SQLite, один писатель), проекции фикстур,
  исследования байткода и ресурсов клиента, стенды.
- `web/` — сайт и loopback-bridge между gateway и Python-хранилищем.
- `client_patch/` — минимальные собственные модули клиента (CPython 2.7.3).
- `local/` — сборки, стенды, доказательства, копии клиента; не в git.

Оригинальный клиент неизменен: `C:\WoT_0.9.1_RU_0717_original` (только чтение);
рабочая копия для патчей — `local/clients/`. Разрешённые пути — `config/project.local.json`.

## Главное правило

**Проект не считается сетевым сервером, пока два независимых настоящих клиента не
разделяют одно авторитетное состояние, находящееся в отдельном серверном процессе.**
Локальные подмены допустимы только как явно обозначенные исследовательские инструменты
и не закрывают приёмку сетевого этапа.
